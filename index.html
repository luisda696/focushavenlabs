Preguntas Frecuentes

¿Qué es exactamente FocusHaven?

No es una plataforma que "hace todo por ti". Es un sistema de arquitectura técnica: te hacemos las preguntas que no sabías que debías responder, estructuramos tu respuesta en especificaciones completas, y generamos prompts que tu IA favorita (GPT-4, Claude, Qwen) convierte en código. Tú necesitas tu propia API key y conocimiento básico para validar el resultado.

¿Por qué necesito mi propia API key?

Porque el procesamiento ocurre en tu cuenta de OpenAI, Anthropic o similar, no en nuestros servidores. Esto significa: más privacidad (tus estrategias nunca pasan por nuestra infraestructura), control total de costos (pagas directamente a tu proveedor de IA), y libertad de cambiar de proveedor cuando quieras.

¿El código generado es mío?

100%. Úsalo, modifícalo, véndelo, regálalo. El valor está en nuestra arquitectura de especificación, que evoluciona constantemente. Si eres desarrollador o agencia, puedes usar nuestros generadores para crear sistemas para tus clientes.

¿Cómo se genera el código?

En tu navegador, mediante tu conexión directa a la API de tu proveedor de IA. Nunca almacenamos tu código, tu estrategia ni tu información personal. Todo fluye: tu navegador → tu API de IA → tu dispositivo. Nuestro backend solo valida que tu clave de acceso a FocusHaven esté activa.

¿Cómo funcionan las claves de acceso?

Cada generador requiere una clave única para desbloquear el módulo. Contacta con soporte para obtener tu clave de acceso personal.

¿Puedo modificar los bots generados?

Absolutamente. El código es 100% tuyo una vez generado. Puedes editarlo, compilarlo o desplegarlo en cualquier entorno que soportes.
